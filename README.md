# 黄金局势 · Android 独立版

手机直接请求公开行情和新闻，本机计算基础指标；可选直接调用付费模型进行新闻、地缘局势与跨市场综合研判。不需要电脑、自建服务器或应用账户；综合研判需要用户自己的 API Key，基础行情不需要。更新数据需要互联网。

当前版本：1.3.1。默认人民币／克，支持美元／盎司切换。新增价格／分批仓位参考看板、价格地图与首页计划摘要。已取消应用内每日次数限制，点击直接启动并显示加载状态。新增用户指定的 Sub2API / GPT / Responses 流式接口与可选 live 检索。以下1.1.0的分析与指标能力继续保留。

这是独立实现的个人研究应用，**不是 GoldMind 官方客户端，也不是原版完整移植**。原版依赖 Python 服务且没有独立 Android 运行模式；调研后采用手机直接取数、本机计算的架构。GoldMind 原仓库保留在本项目旁的 `../GoldMind/`，仅作为调研参考，没有修改其源码。

## 安装与使用

安装文件：`dist/GoldRadar-1.3.1.apk`，Android 8.0 及以上，适用于 ARM / ARM64 / x86 / x86_64（无本地二进制库）。

1. 将 APK 通过微信文件、USB 或其他文件传输方式发送到手机。
2. 从手机文件管理器打开，按系统提示允许该文件管理器“安装未知应用”。
3. 安装后打开“黄金局势”，联网后自动刷新。各源独立加载，慢的源不会阻塞已返回数据。
4. 行情页查看报价，局势页查看指标及综合研判，消息页打开原文，来源页检查更新时间与失败原因。
5. 点“局势 → 配置模型”。默认 Sub2API 服务 `https://justproxy.dui88.com`，模型 `gpt-6.1-sol`，接口 `/v1/responses`。可在下拉列表选择GPT模型、手工填写模型ID，或从服务器刷新模型列表。Bearer Token和可选actor请求头只在原生弹窗填写，配置窗口禁止系统截图。也保留DeepSeek与通义选择，各供应商密钥分别加密保存。
6. 点击“开始综合研判”直接启动付费调用。Sub2API默认开启live：先实际联网检索取证，再综合分析并检查反证。关闭live或选择其他供应商时，仍采用初稿→复核。每次最多两次模型调用，检索工具可能额外计费；无应用内每日次数限制，失败不自动重试。这些步骤不代表独立专家共识。
7. 报告分别给出1、3、5个交易日的方向或观望、依据、失效条件，并保留证据和到期核验记录。它不是90%准确率预测器；新闻与数据缺失会明确说明。

本机签名用于个人侧载；没有上架 Google Play。后续升级需保留仓库外的同一签名材料。签名密码使用macOS钥匙串，详见 [SECURITY.md](SECURITY.md)。不要把私钥或密码放进APK、GitHub或源码交付包。

## 已实现

- 腾讯财经纽约黄金报价与新浪美元指数报价，优先展示时间较新的可用报价。
- Yahoo Finance 六个月黄金、美元指数、美债 10 年名义收益率、USD/CNY、WTI原油、白银、铜、标普500和VIX日线，两台查询主机自动切换。
- 近 60 个日线观测图，MA20 / MA60、简单平均 RSI14、20 日波动率。
- 四项解释性方向因子、分歧状态、数据过旧时停发方向判断。
- 基于历史波动的未来五日 ±1σ 尺度，明确不等于预测目标或校准区间。
- 国际期货参考价折算人民币元/克，时间差超过 24 小时或数据过旧时不计算；不是国内零售价。
- 中文黄金、地缘局势、跨行业新闻聚合RSS及美联储官方公告，按时间排序，原文链接通过系统浏览器打开。
- 可选综合研判：近期行情与最多32条去重RSS新闻标题摘要，1/3/5日判断、引用证据、正反路径、风险及失效条件；GPT live模式另可使用真实工具检索来源。
- 原生密钥配置，Android Keystore支持的AES-GCM加密存储；网页读不到密钥。仅固定官方供应商和用户明确指定的Sub2API HTTPS端点，不接受任意地址。
- 报告前向留档与到期描述统计：正确、错误、观望、待结算都保留；数据不足不会生成准确率。
- 最近一次成功数据的本机缓存；失败原因、缓存标记及时间保留。
- HTTPS；无广告、应用账户、埋点或交易接口。可选付费模型调用只在用户手动开始后发生。

没有完整移植GoldMind，也没有接入机构目标价、全球央行购金、ETF申赎、实际利率、CFTC持仓及可靠经济事件预期日历；没有推送预警、自动交易或已验证的获利策略。网络与数据源可能限制访问，尤其是 Yahoo / Google；国内报价可独立展示，但不足以单独生成宏观趋势判断。

## 规则与数据口径

分析规则和阈值在应用“来源”页完整说明，唯一实现位于 `app/src/main/assets/engine.js`。基础规则没有经过样本外获利验证，不输出未经验证的上涨概率或准确率宣传。综合研判使用模型解释新闻和市场影响；仅有标题摘要时必须承认信息不足。方法调研与边界见 [RESEARCH.md](RESEARCH.md)。

Yahoo 的 GC=F 是未做自行展期调整的黄金连续期货，不是 XAU/USD 现货；`^TNX` 是名义收益率，不是实际利率。日线可能包含当日未收盘观测。周末或休市时价格不变不等于故障；超过四个自然日的数据不参与方向分析。

手机请求固定的 HTTPS 行情 / RSS 地址。原始响应在 Android 原生层解析后交给本地界面；WebView 不加载第三方网页，原文由外部浏览器打开。选择综合研判时，所列公开证据将直接发送到用户配置的模型供应商，API密钥仅从原生加密存储读取。无自建代理服务，手机 IP 会被所访问的公开数据源看到。

## 构建

需要 Python 3、JDK、Android SDK Platform 35、Build Tools 35.0.0。构建只使用 Android 系统 API，无 Maven / npm 运行依赖。

```sh
export ANDROID_HOME="$HOME/Library/Android/sdk"
export JAVA_HOME="/Applications/IntelliJ IDEA.app/Contents/jbr/Contents/Home"
python3 tools/build.py
node tools/test-engine.cjs
node tools/test-research.cjs
python3 tools/test-proxy.py
```

`tools/build.py` 编译资源、Java 和 DEX，zipalign 后本机签名并验证，输出 APK 与 SHA256。删除 `build/` 可清理编译中间文件；卸载应用会清除手机缓存、研判记录和加密密钥。清除页面行情缓存不会删除研判记录或密钥；密钥可在“配置模型”里单独删除。研判记录不设条数上限，不自动删除历史；设备存储不足时会明确提示保存失败。尚无导出界面。

调研与 APK 验证记录见 `VALIDATION.md`。

## Sub2API 协议与数据边界

按 [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create) 和 [Web search](https://developers.openai.com/api/docs/guides/tools-web-search) 格式实现，并按代理实测适配。这不意味着代理由OpenAI运营，或所有标准参数都可用。该代理拒绝 `max_tool_calls`，本应用不发送该参数；工具执行次数不等于模型请求次数。

live使用 `web_search` 和 `external_web_access=true`，只在收到 `response.completed` 后解析结果。断流、未执行工具或缺少可核对来源时明确失败，不静默降级冒充live结果。候选URL必须出现在实际工具来源或引用中才赋予W编号；来源发布时间是模型提取、未独立验证，不把检索时间当新闻发生时间。

Sub2API是用户指定的第三方代理，模型证据与凭据会发送给该代理；请求虽设置 `store=false`，仍不能代表代理承诺不留存。费用、模型路由和数据处理以该网站为准。旧版密钥会迁移到原供应商的专属加密槽，不会把DeepSeek或通义密钥发给Sub2API。

## 价格与仓位参考看板

新报告要求模型返回 actionPlan：当前等待状态、买入／减持区间、比例、相对报告价和最新同品种报价的涨跌幅、触发条件、定价依据、失效条件及最长24小时复核期限。首页显示首档摘要，报告显示详细看板、比例条、历史价格与模型区间地图。旧报告不补造计划。图表不是未来走势预测。

买入比例以预先计划投入黄金的资金为固定基数，减持比例以报告时原有黄金持仓为固定基数；同侧合计不超过100%，不按每次剩余仓位重算。属于无杠杆的一般性示例，不针对个人资产，也不适用于期货保证金。参考价格是GC=F连续期货美元／金衡盎司，不能直接当成现货、其他合约或国内零售价。证据不足可不给区间，等待状态不等于到价即可操作。

旧报告的参考价、区间和比例不随刷新改写；最新报价和相对最新价的距离会重新显示，过旧报价不展示。超期明确提示重做，重大事件亦会使计划提前失效。现有前向命中率只结算方向，不评价这些区间／比例的盈利能力。

## 人民币显示

首页、技术价位、波动尺度、买卖区间、失效价和价格地图默认人民币／克；页面顶部可切换美元／盎司并保存偏好。比例不变。使用1金衡盎司=31.1034768克，美元价×USD/CNY÷该常数。报告区间使用报告证据中的汇率快照，最新报价使用最新有效汇率，距最新人民币价百分比包含汇率差异。曲线用报告时固定汇率整体换算，不是假定已接入人民币历史行情。正文中能对应到黄金证据／计划价格锚点的数字附人民币折算，原始美元数字同时保留，其余数字不替换。

汇率缺失或时间不匹配时人民币显示不可用，可切换美元；不使用固定预设汇率。这是国际期货价格换算，不是国内金店、银行或黄金ETF的实际成交价。旧报告无需新增模型调用即可换算。

## 敏感信息存储

签名私钥已改为仓库外存储，密码由macOS钥匙串保管；构建不会在项目目录生成签名或明文密码。应用内模型密钥由每位用户自行填写并在其手机加密保存。Git提交和推送前增加秘密格式及私有文件检查；新克隆目录需执行 `git config core.hooksPath .githooks`。迁移、权限、备份与检查范围见 [SECURITY.md](SECURITY.md)。
