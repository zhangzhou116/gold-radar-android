# 使用黄金局势

## 首次启动

应用自动获取行情。顶部可切换“人民币／克”和“美元／盎司”，默认人民币。人民币数字是国际黄金期货换算参考，不是国内金店、银行或黄金ETF成交价，国内溢价、手续费及价差没有包含。

四个页面：“行情”看报价和摘要，“局势”做综合研判，“消息”看新闻原文，“来源”检查数据时间、失败情况和缓存。

## 填写自己的模型Key

1. 到你信任的供应商自行开通API账户、取得Key及可用模型，了解价格。不要向作者或GitHub提交Key。
2. 打开“局势→配置模型”，选择供应商。
3. 可选DeepSeek官方、通义千问中国站，或内置Sub2API第三方服务。Key必须和所选服务匹配。当前不能直接填写任意代理地址；更换服务地址需要修改源码，不能只拿其他平台的Key粘贴。
4. 选择模型或手动输入供应商实际支持的ID。Sub2API默认gpt-6.1-sol，可用自己的Key点击“从服务器刷新可选模型”。默认ID不代表你的账号一定有权限。
5. 填Bearer Token/API Key。可选actor请求头只有服务明确要求时才填。点击保存。手机加密保存Key，网页不显示，安装包不含作者凭据。
6. Sub2API可开启live联网搜索，服务和模型必须支持Responses与web_search。DeepSeek/通义走现有行情新闻证据分析，不等于开启live全文检索。

内置第三方地址为https://justproxy.dui88.com，项目不代表该代理、也不保证其价格、模型路由、可用性或数据政策。使用哪个服务就把Key和公开研究证据发送给哪个服务用于鉴权和分析；不会扣作者账户额度。

## 开始研判与费用

刷新行情，确认局势页有足够黄金、跨市场和新闻证据，然后点“开始综合研判”。直接开始，无二次弹窗；加载动画与文字显示取证／分析步骤，期间防止重复点击。成功后自动留档，失败不自动重试，无应用内每日次数上限。

普通行情刷新不调用大模型。一次研判最多两次模型请求，供应商按输入、输出Token及可能的搜索工具收费；失败请求是否收费以供应商为准。付费购买软件与供应商模型费用是两回事。

## 一眼看报告

- “现在先等一等”：当前不操作，查看“现在等什么”，有参考区间也不代表现在应买卖。
- 分批买入：比例按预先计划投入黄金的资金算，各档均用同一初始基数。
- 分批减持：比例按报告时已有黄金持仓算，不是做空，也不是按每次剩余量递减计算。
- 例如两档20%、30%指同一计划资金合计50%；并非把全部资产投入黄金的建议，不能直接当作杠杆期货保证金比例。
- 价格地图画的是历史日线及模型区间，未画未来预测路径。展开每档看触发条件、反证和依据，到价本身不代表可以买卖。
- 旧报告保留原价、区间、比例及当时汇率，最新价另列；过期、重大消息或条件失效后重新分析。
- 1/3/5交易日方向及前向记录不是保证收益。尚未验证90%正确率；仓位和价格计划也未经盈利验证。

## 常见问题

- 401：Key错误、服务不匹配或鉴权请求头不正确。
- 402：服务账户余额不足。
- 429：供应商限流，并非应用每日次数限制。
- upstream_error／不完整：服务上游失败，应用不会发布半份报告；稍后自行决定是否再调用。
- 没有足够证据：先刷新，在“来源”查看失败数据，不要把缺失当成市场中性。
- 人民币价显示不可用：缺少有效汇率或时间不匹配，可切换美元查看原始价格。
- 看到观望：是模型的等待结论，不代表调用失败。
- 删除密钥：在配置页点“删除该服务密钥”；卸载应用会同时丢失密钥和本地报告。清除行情缓存不会清除模型Key或报告。
